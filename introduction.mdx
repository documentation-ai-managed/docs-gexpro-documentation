## Getting Started

To begin using AsiaQuant solutions, first determine your specific needs from our three core areas: network video, access control, or audio solutions. Our team provides expert consultation to help you choose the right combination of technologies for your business transformation goals.

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  // Initialize AsiaQuant SDK
const client = new AsiaQuantClient({
  apiKey: 'your-api-key',
  endpoint: 'https://api.asiaquant.com'
});

// Connect to video stream
await client.connectVideoStream('stream-id');
  ```
  ```python
from asiaquant import Client

client = Client(api_key='your-api-key')
response = client.get_video_analytics()
print(response)
  ```
